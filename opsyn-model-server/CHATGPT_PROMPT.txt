**Project**: AI system that generates Activepieces workflow JSON from natural language prompts

**What I Built**:

1. **Fine-Tuned LLM Model**
   - Base: Qwen2.5-Coder-7B-Instruct (7B parameter code LLM)
   - Method: PEFT/LoRA fine-tuning (rank=32, alpha=64)
   - Framework: LlamaFactory
   - Dataset: 381 workflows (instruction-output pairs)
   - Why LoRA: Memory efficient (4-8GB vs 56GB+ for full fine-tuning)

2. **FastAPI Server** (`server_v2.py`)
   - Serves model via REST API
   - Main endpoint: `/generate-workflow` (generates + post-processes)
   - Deployed on Modal cloud (A10G GPU)

3. **Post-Processing Pipeline** (`postprocessor_v2.py`)
   - Fixes model output to ensure valid JSON
   - Schema fixes (field names, missing fields)
   - Name normalization (piece/trigger/action names)
   - Structure correction (misplaced actions, router children)
   - Uses smart matching for name fixes

4. **Smart Matching System** (`smart_matcher.py`)
   - NLP techniques:
     * Text normalization (camelCase → snake_case)
     * Fuzzy string matching (Levenshtein distance via rapidfuzz)
     * Token-based similarity (Jaccard similarity)
     * Cascading matching (exact → normalized → fuzzy → token)
   - Conservative: only fixes if confidence ≥ 85%

5. **Data Engineering Pipeline**
   - Validation scripts (`comprehensive_validation.py`, `verify_dynamic.py`)
   - Fixing scripts (`fix_all_final.py`, `fix_final_train.py`)
   - Validated 381 workflows against codebase
   - Fixed schema violations, invalid names, placeholder conditions

**Pipeline Flow**:
User Prompt → LLM Generation → Raw JSON → JSON Extraction → Post-Processing (schema fixes + smart matching) → Valid FlowTemplate → Activepieces Import
